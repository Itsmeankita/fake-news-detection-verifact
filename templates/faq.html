Questions

Frequently asked questions.

Is VeriFact a fact-checker?

No. It's a style/pattern classifier — it estimates how similar an article's writing style is to known real vs. fabricated articles. It doesn't verify facts against a knowledge base the way a human fact-checker or a site like Snopes does.

Why did it get my example wrong?

No text classifier is 100% accurate. The model was trained on a specific dataset (US politics/news-heavy) — articles very different in topic, language, or style from that training data are more likely to be misclassified.

What data was the model trained on?

The ISOT Fake and Real News Dataset from Kaggle — about 45,000 labeled articles, roughly half real (Reuters) and half fabricated/hyperpartisan. Full details are on the Analytics page.

Does it work in languages other than English?

Not currently — the text cleaning, stopword list, and training data are all English-only. Multi-language support would need a translated or separately labeled non-English dataset.

Is my pasted text stored anywhere?

Only if you're logged in — in that case a short preview (up to ~280 characters) is saved to your personal history so you can review past checks. If you're not logged in, nothing is stored.

Can I use this via an API?

Yes — every logged-in user gets an API key (visible on your Dashboard) and the same /api/predict endpoint the website uses. See the README for request/response examples.

What if the URL detector can't read a page?

Some news sites block automated requests or load content via JavaScript, which a simple scraper can't execute. If URL detection fails, copy the article text directly into the Detect page instead.
